# electronics-data-integration

Лабораторная работа №1 по дисциплине "Разработка баз данных"
Выполнил студент группы Б9124-09.03.03пикд Гдалёва Алина

## Цель

Приобретение практических навыков по сбору, обработке и интеграции разнородных данных из публичных веб-источников, проектированию реляционной базы данных и созданию простого веб-приложения для работы с этой базой.
